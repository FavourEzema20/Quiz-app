# Quiz app

## Description

This is a simple quiz app built using HTML, CSS and JavaScript. This project presents multiple-choice questions to users, tracks their score, and displays results at the end.

## Features

- Display one question at a time.

- Track Scores.

- Instant feedback (correct / incorrect answers).

- Progress Indicator.

- Multiple-choice answer buttons.

- Restart quiz functionality.

## How it Works

The quiz app starts automatically when the page loads. A question is displayed with multiple answer options.

The user selects an answer:

- Correct answers are highlighted in green,
- Incorrect answers are highlighted in light red,
- The Next button appears after selection.

The quiz continues until all questions are answered.

At the end, the final score is displayed and the user can restart the quiz.

## Technologies Used

HTML: Structure of the app
CSS: Styling and layout
JavaScript: Logic and Interactivity
